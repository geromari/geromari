### 🌟 Flagship Project: USTASY

<div align="center">
  <h3>🏆 USTASY — Smart Online Examination & Learning Ecosystem</h3>
  <p><i>O'zbekiston milliy sertifikati va barcha turdagi kirish imtihonlariga tayyorgarlik ko'rish uchun mo'ljallangan zamonaviy, tezkor va sun'iy intellektga asoslangan online test platformasi.</i></p>
</div>

> **USTASY** is an enterprise-grade EdTech and examination platform designed to prepare students for national certificates and university entrance examinations through adaptive practice, real-time analytics, and automated AI guidance.

- 🎓 **Practice Mode (Amaliyot):** Self-paced question solving with immediate answer validation and comprehensive algorithmic explanations.
- ⏱️ **Exam Simulation Mode (Haqiqiy Imtihon):** Realistic exam environment with strict timers, automatic submission, and simulated testing pressures.
- 📊 **Precision Analytics & Tracking:** Granular tracking of topic-by-topic accuracy, historical progress, and automatic weakness identification.
- 🤖 **AI-Driven Remediation:** Personalized learning recommendations and targeted question drills based on diagnosed weak topics.
- 🛡️ **Comprehensive Admin Suite:** Real-time question lifecycle management (CRUD), multi-type question support (Single, Multi-Choice, Short Numeric Match), and student cohort monitoring.

**Tech Architecture:**
- **Frontend:** Next.js 16 (App Router) • React 19 • TypeScript • Tailwind CSS v4
- **Backend:** FastAPI • Python 3.14 • SQLAlchemy • Pydantic v2
- **Database & Infrastructure:** PostgreSQL 16 (psycopg3) • Docker • Uvicorn • Render / Vercel
